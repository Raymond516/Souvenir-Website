## 🎁 Souvenir Website

Selamat datang di **Souvenir Website**! 

This project is a website platform built using **PHP** and **Bootstrap 5**, specifically designed to showcase a catalog of souvenir products. The website was developed with a focus on a modern, interactive user interface (UI) and places great emphasis on visual comfort (UI/UX) for its visitors.

---

## Main Feature

* Interactive Product Catalog: Displays a list of products using a modern *card* layout, complete with elegant *hover* effects and smooth image *zoom* transitions.
* Admin & User Dashboards: Clean and well-organized interface panels for managing data, complete with interactive tables and a clear navigation system.
* Chat Feature (Live Chat UI): Provides a modern, custom messaging/chat interface, using a gradient *bubble chat* style and a customized *scrollbar*.
* Responsive & Eye-Friendly Design: Uses a custom *design system* that makes the website easy on the eyes and displays perfectly on various screen sizes (Desktop, Tablet, and Mobile).

---

## Technologies

* Programming Language: PHP (Native)
* Markup & Styling: HTML5, CSS3 (using *Custom CSS Variables* and transition animations)
* Frontend Framework: Bootstrap 5
* Typography: Integrated with Google Fonts (Space Grotesk, Inter, and IBM Plex Mono)

## Guide to Running the Project Locally

If you want to run this project on your local machine, please follow these steps:

1. Set Up Your Environment: Make sure your computer has a local web server application installed, such as **XAMPP**, **Laragon**, or a similar program.
2. Make sure you have imported the SQL database in the Database folder > responsive_web_promosi.sql
